# Action 卡片在后续轮次仍可操作

[English](guide.md) | 中文

## 变更

过去，新提案会把早先尚未开始的卡片标记为 `replaced`。重新打开会话后，这些卡片会再次提供操作。每张卡片都保留自己的决定记录，包括已忽略的提案和已开始的任务。每轮仍只接纳第一个合法的 `action-card` 代码块。

## 迁移

1. 打开一个在不同轮次收到过两张提案卡片的会话。Host 遇到版本 3 的检查点时会从会话日志重建 `actionCards` 投影，无需编辑会话文件。
2. 确认每张尚未操作的卡片都有相应的控件。对不再需要的提案选择**暂不需要**。
3. 如果插件读取 `ActionCardView.decisions`，请按提案的 `cardId` 读取决定。没有决定记录表示卡片尚未开始，可以删除对原有共享阶段 `replaced` 的处理。
