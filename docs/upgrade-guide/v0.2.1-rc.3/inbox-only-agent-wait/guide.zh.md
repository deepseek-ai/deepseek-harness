# Agent 等待需要收件箱输入

[English](guide.md) | 中文

## 变更

`wait_agent` 仅等待调用 Agent 的下一步收件箱。任务创建、分配、完成和其他任务更新不再结束正在进行的等待，也不添加收件箱消息或启动空闲 Agent。排队的下一轮输入和其他 Agent 的状态变化同样不会结束等待。

已有下一步输入时立即返回；新消息、完成通知和用户引导会结束等待，但不消费输入。超时和取消行为保持不变。

## 迁移

1. 修改任务后，需要任务所有者或其他成员处理更新时使用 `send_message`。不要依赖任务修改来结束 `wait_agent`。
2. 行动前读取当前任务状态；任务更新不是消息，也不是开始新轮次的指令。
3. 验证任务更新不会结束空收件箱上的等待，然后发送消息，确认等待返回 `timedOut: false`。
