# macOS Computer Use 应用身份

[English](guide.md) | 中文

## 变更

应用授权使用原生应用提供的、区分大小写的 Bundle ID。不同路径的版本和副本共用许可与撤销决定，不受签名状态影响。缺少 Bundle ID 的应用使用规范化可执行路径，也可以“始终允许”。在该路径重启或替换可执行文件会沿用许可，移动文件则需重新授权。运行中的有效 Bundle ID 不依赖可执行路径。授权记录可以省略 executablePath，权限页此时显示名称，不显示路径提示或图标。已有记录仍可读取，要求该字段的旧版本无法读取缺少路径的新记录。profile 存储位置和对话范围保持不变。

受影响的是保存过路径和签名授权的 macOS 用户，包括通过旧 `allowedApps` 配置导入授权的用户。这些授权不匹配新身份。旧记录仍可查看和撤销，但不会自动授权其他安装副本。新旧条目可能显示相同名称和路径，权限页没有区分它们。其他程序声明已批准的 Bundle ID，或替换路径授权对应的可执行文件时，也会继承许可，这项规则不验证发布者身份。

## 迁移

1. 重新选择应用前，在 Computer Use 应用管理中撤销该应用的所有“始终允许”条目。如果升级后已经批准过，也移除该应用的全部条目，无须判断哪条是旧记录。
2. 在“不允许访问的应用”中，对该应用点击“允许再次询问”，避免先前的拒绝或撤销阻止下次提示。重新选择应用并批准所需范围。“始终允许”覆盖当前 profile 中相同 Bundle ID 的所有版本和副本。
3. 选择具有相同 Bundle ID 的另一个已安装副本，确认在许可范围内不再询问。需要停止所有副本的访问时，撤销共用许可。使用不同 Bundle ID 的版本仍需分别批准。
