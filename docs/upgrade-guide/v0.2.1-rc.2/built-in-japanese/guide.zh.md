# 内置语言取代重复的语言包

[English](guide.md) | 中文

## 变更

locale 插件注册 `ja`、`es`、`fr`、`de`、`ru` 和 `pt`，并提供 `common`、`settings.locale` 以及内置 UI 插件的字典。使用这些 id 的第三方语言包会因语言或字典已注册而加载失败，包括按此前 README 日语或法语示例编写的语言包。

## 迁移

1. 在语言包的 client 入口中，删除这些 id 的 `ctx.locale.addLanguage(...)`，以及内置插件已提供的命名空间下的字典注册。保留自己插件所拥有命名空间的翻译。
2. 如果语言包代表不同的语言变体，为语言定义及其字典注册独立的 BCP 47 风格 id，例如 `fr-CA`，代替内置 id。
3. 启用语言包并重新加载应用。确认启动时没有重复注册错误，且选择目标语言后显示对应译文。
