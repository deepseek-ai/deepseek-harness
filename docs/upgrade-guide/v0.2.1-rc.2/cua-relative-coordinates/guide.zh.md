# CUA 相对坐标使用 0～999

[English](guide.md) | 中文

## 变更

`cua` 工具和应用或窗口对象方法在 `relative: true` 时接受 0～999 的整数，原范围为 0～1000。坐标仍使用千分比：除以 1000 后按窗口尺寸缩放，并限制在窗口内。0～999 的坐标保持原有落点。这影响 `click`、`hover`、`scroll` 和 `drag` 的起终点。绝对截图像素和 AX 元素编号保持原有行为。

## 迁移

1. 更新生成相对坐标的脚本和提示。0～999 的现有数值保持不变。将旧端点 1000 改为 999，例如对原本合法的旧坐标使用 `Math.min(oldValue, 999)`。在较大的窗口中，999 可能比原端点 1000 更靠内。
2. 读取新的窗口状态后，使用 0～999 的整数坐标调用相应动作，再读取新状态验证结果。相对坐标为 1000、负数或小数时，会在原生输入前被拒绝。
