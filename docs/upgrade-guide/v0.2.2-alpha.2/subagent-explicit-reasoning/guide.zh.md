# subagent 推理强度覆盖要求显式路由

[English](guide.md) | 中文

## 变更

启用模型选择的委派工具要求同一次调用同时提供 `provider` 和 `model`，否则拒绝 `reasoning_effort`。此前，仅指定强度的调用可以使用配置或继承的路由。拒绝发生在创建子级之前。

显式提供提供方／模型组合但省略 `reasoning_effort` 时，使用所选模型的默认强度，即使该组合与父级或配置的子级路由相同。此前，路由不变时可能保留配置或父级强度。省略全部三个工具字段时，仍保留配置的子级默认值与现有回退行为。

## 迁移

1. 更新仅发送 `reasoning_effort` 的提示、skill 和工具调用生成方：补齐已授权的 `provider` 和 `model`，或省略全部三个字段以使用默认子级选择。通过 `list_subagent_models` 查询已授权路由与支持的强度 ID。
2. 选择路由时若要保留某个强度，显式传入 `reasoning_effort`。
3. 确认仅指定强度的调用返回缺少路由的错误，且没有启动子级。对于完整路由，检查子级日志中的 `request/header` 配置：省略强度时应采用该模型的默认值，而不是父级选择的强度。
