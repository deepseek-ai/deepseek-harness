# 桌面端字号快捷键占用部分自定义组合键

[English](guide.md) | 中文

## 变更

桌面端保留 `Cmd`/`Ctrl` + `=`（包括输入 `+` 的 `Shift` + `=`）和 `Cmd`/`Ctrl` + `-`，用于一起调整正文、代码和终端字号。macOS 使用 `Cmd`，Windows 和 Linux 使用 `Ctrl`。使用这些组合键的自定义绑定，包括与其重叠的双键序列，仍会保存，但不再执行。Web 端快捷键行为不变。

## 迁移

1. 在桌面端打开「设置 → 通用 → 键盘快捷键」，找到标记为与字号快捷键冲突的自定义绑定。
2. 为该操作录制不冲突的组合键，或选择「移除」禁用其快捷键。操作的默认快捷键不冲突时，也可以选择「恢复默认」。
3. 尝试重新绑定的操作，再按 `Cmd`/`Ctrl` + `=` 和 `Cmd`/`Ctrl` + `-`。确认设置中的三组字号一起变化，并在重新打开桌面端后仍保留。
