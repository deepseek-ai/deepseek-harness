# Windows 应用权限

[English](guide.md) | 中文

## 变更

Windows 自动电脑操作不再按应用自行声明的 AUMID 授权，而是使用操作系统提供的包内应用身份，或由窗口 AUMID 限定的规范可执行文件路径。旧决定不能授权这些新身份。选择应用时，辅助程序会撤销对应的旧决定。显示名称和图标不决定权限范围。应用发现返回不透明的 ID，可能与原来的 AUMID 或路径不同。

## 迁移

1. 使用更新后的 Windows 辅助程序及其构建输出中的全部文件重启 DSH。重启使用同一 profile 的所有 Host。
2. 通过 `cua.listApps()` 或 `cua.findApps()` 发现应用，将返回的 ID 原样传给 `cua.getApp()`。替换脚本中保存的发现 ID；能唯一解析到一个应用的可执行文件绝对路径仍然有效。
3. 在新的审批请求中确认应用名称与路径。选择本会话访问，或显式保存授权。不要将旧 `allowedApps` ID 复制为新授权。
4. 检查自动电脑操作插件页。选择应用后，对应旧条目会被撤销。重复选择同一身份会复用新决定，选择其他可执行文件需要单独授权。
