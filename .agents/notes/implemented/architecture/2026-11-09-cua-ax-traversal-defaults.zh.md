# Agent Note: AX 树遍历的默认值和单次读取上限

Status: implemented

[English](2026-11-09-cua-ax-traversal-defaults.md) | 中文

## 问题

读取深度较小时，控件可能位于窗口中被截断的分支里。为了找到这个控件而调高配置值，会让以后的读取也可能访问更多节点、返回更多文本。

## 决策

读取辅助功能树时，Host 分别处理 `maxElements` 和 `maxDepth`。调用方显式传入的值只对本次读取生效，可以高于或低于配置值。省略的参数使用平台配置。原生实现在遍历时执行自身的硬上限。macOS 的粘贴操作没有遍历参数，查找粘贴菜单时始终使用配置值。

## 考虑过的替代方案

**把配置值作为每次读取的硬上限。** 如果日常读取使用较小的配置值，即使平台支持读取更大的树，调用方也必须先修改配置才能看到被截断的分支。允许单次覆盖后，调用方可以单独扩大这次读取的范围，下次读取继续使用原有配置。

## 影响

调低配置值可以缩小常规读取的范围。显式请求更大的树可能耗时更长，也可能返回更多文本。原生调用仍受超时和响应大小限制。默认值见 [macOS 配置表](../../../../packages/experimental/cua-macos/README.zh.md#use-this-package)。
