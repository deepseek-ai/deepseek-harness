# Agent Note: 会话可写目录 effect

Status: implemented

[English](2026-10-26-session-writable-directory-effects.md) | 中文

## 问题

记忆插件需要允许 agent 在工作区之外写入，同时不向所有 Session 授予相同目录。部署级根目录无法表达只为一个 Session 启用的插件，或随插件卸载而结束的授权。

## 决策

sandbox-policy 服务拥有以活跃 Session 身份为键、受 effect 生命周期管理的目录注册。配置授权仍然共享；运行时授权只适用于指定 Session。每次解析捕获当前授权的并集，现有请求上下文日志记录向模型展示的目录。恢复与派生需要重新注册，而非从历史文本恢复权限。

注册清理影响后续操作，不影响已经解析策略的调用或运行中的进程。这明确允许持久终端与 PTC 环境在停止前保留启动时的授权。需求是在不协调进程取消、不丢失保留状态的情况下更新运行中 Session 的后续执行。这仅针对额外目录收窄了[保留 PTC 沙箱决策](2026-10-08-persistent-ptc-sandbox.zh.md)中不同策略禁止复用的限制；模式变化失效与单次提权清理保持不变。

不存在、不是目录或经过符号链接的额外路径会以 `SandboxInvalidRootError` 阻止执行，错误指出路径及其问题。静默跳过路径会隐藏无效授权，使执行时的权限与请求的权限不同。注册时检查路径写法；执行限制时每次验证物理目录，不保留先前的解析结果。符号链接仍被禁止，使配置授权和插件授权遵循相同的验证规则。

## 考虑过的替代方案

**共享的可变额外根目录。** 在一个 Session 中启用记忆，也会授权使用同一服务的无关 Session。

**立即撤销进程权限。** 现有沙箱在启动时应用授权。停止并重新创建进程会丢失终端或 PTC 状态，并需要超出已接受的后续操作需求的清理协调。

**将运行时授权持久化为 Session 权限。** 回放此类授权可能在提供授权的插件已被移除后继续授权目录。当前插件组合拥有这些授权。

## 影响

同一目录的独立注册不会随另一个所有者的清理而移除。移除注册无法撤销重叠的配置授权或工作区访问权限。运行中的进程可能保留已移除的授权，或缺少新添加的授权；新进程使用当前策略。Windows 子进程忽略额外根目录，文件工具则执行这些授权；[Windows 范围决策](2026-10-29-windows-file-tool-directory-grants.zh.md)记录此限制。针对性覆盖检查 Session 隔离、重复注册的所有权、插件卸载、文件系统拒绝与修改、请求上下文，以及保留 PTC 环境的启动权限。
