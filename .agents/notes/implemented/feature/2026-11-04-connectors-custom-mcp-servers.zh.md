# Agent Note: “连接器”标签中的自定义 MCP 服务器

Status: implemented

[English](2026-11-04-connectors-custom-mcp-servers.md) | 中文

## 问题

用户要添加 MCP 服务器，只能编辑 profile 的组合配置，而插件页上看不到在那里配置的任何服务器。[MCP 管理器](../../../../packages/mcp/mcp-manager/README.zh.md)已经从 Settings 读取 `servers`，通过凭据引用解析密钥，能探测服务器，也能为 OAuth 服务器完成授权；缺少的是一个编辑这些条目、并显示 OAuth 服务器账号的页面。本地 stdio 服务器会以用户权限在 Host 上运行命令，所以是否允许浏览器定义这类服务器，需要明确决定。

## 决策

[“连接器”标签](../../../../packages/experimental/client-ui-connectors/README.zh.md)列出管理器 Settings 命名空间中的服务器，并通过它的 Host 服务提供的 `connectors` Remote 编辑它们。该服务把每次保存、删除和开关作为一次操作执行，遇到第一个被拒绝的步骤即停止，并用 `settings.mutate` 写入条目，管理器的校验、revision 检查和组合分层因此原样生效。Bearer 令牌以及标为密钥的请求头或环境变量行保存在凭据服务中，引用名为 `MCP_<名称>_<字段>`，条目里只保存 `${credential:REF}` 模板。删除服务器会经管理器退出它的 OAuth 登录，并删除它拥有的密钥；保存编辑时先写入条目，再保存表单中输入的密钥，并删除条目不再引用的密钥；两者都不会删除其他条目仍在引用的密钥。

标签允许添加 stdio 服务器。保存启用的本地命令前，会先显示风险确认：写明命令，并说明它会以用户权限在这台电脑上运行、不经过沙箱；用户确认后才写入条目。自定义服务器不属于连接器：它们保存在管理器的设置中，“连接器”bundle 关闭时仍会运行。

Host 服务把每个配置的 OAuth 服务器以键 `mcp:<名称>` 登记到 [`dsh-mcp-account`](../../../../packages/mcp/mcp-account/README.zh.md)，不带 bundle 包，文案中写出服务器名，因此它的账号显示和操作都像连接器一样来自 Host。已启用的 OAuth 服务器在列表行中的状态，以及它页面上的账号区块，都通过 [`ui-connector-account`](../../../../packages/client/ui-connector-account/README.zh.md) 的 `connector.account` 组件工厂渲染。

## 考虑过的替代方案

**给管理器增加写入方法。** 这会重复 Settings 的 revision 检查、分层和持久化，并多出一条写同一批条目的路径。

**不允许浏览器添加 stdio。** 本地服务器是添加自定义服务器的主要原因之一，而 Desktop 的页面就运行在 Host 所在的电脑上；改为在确认中写明命令。

**由浏览器写入。** 浏览器可以像其他设置页那样依次保存密钥、退出登录、写入 Settings；但退出登录属于账号逻辑，管理器只向 Host 上的调用方提供退出登录，而且步骤顺序和第一个拒绝应当在同一次操作中处理。

**在浏览器中镜像管理器的服务器。** 在浏览器中把管理器的每个视图映射成账号，会重复 Host 上的账号展示逻辑，还需要把管理器的授权方法作为 Remote 操作提供；在 Host 上登记账号则复用 MCP 账号服务和连接器账号注册表。

**为不使用 OAuth 的服务器也登记账号。** 这样列表行可以把管理器的连接状态显示为只有“重试”的账号，但这类服务器并没有账号；它页面上的连接测试会显示能否连接。

**在“连接器”标签里另写一个账号区块。** 这会重复连接器账号的授权尝试处理、授权页打开和通知。

## 后果

可以写入 Settings、或能访问仅限所有者的 `connectors` Remote 的浏览器，能让 Host 运行命令；“连接器”标签是提供这一能力的界面，并会先请用户确认。自定义服务器与某个连接器的服务器同名时，条目存在期间该连接器无法加载，两者也共用授权 `mcp-client/<名称>`。OAuth 服务器的名称必须符合凭据键段的格式：小写字母、数字和 `-`，以字母开头。只在大小写、`-` 和 `_` 上不同的名称和行名会被拒绝，因为它们会共用同一个凭据引用；自身 `MCP_<名称>_` 引用被其他服务器条目使用的保存同样会被拒绝。
