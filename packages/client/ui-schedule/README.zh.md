# @deepseek-ai/dsh-client-ui-schedule

[English](README.md) | 中文

## 概述

自动化任务页和右侧栏任务页签使用同一编辑器处理任务规则、已保存的投递记录、删除及会话导航。手动创建和执行目标选择使用宿主的 Schedule 服务；会话卡片、页头时钟和会话行标记保留现有位置。

## 使用本包

宽度小于 768px 时，任务列表使用 20px 的左右内边距，与插件页一致。

发布的 Web 组合将 `ui-schedule` 与宿主 Schedule 一起挂载。自动化任务侧栏入口打开任务列表，不选择或激活会话。“新建”和相邻菜单的“在会话中创建”都会进入新会话，按当前界面语言预填简短的任务创建提示，供用户补充并发送。若复用空白会话，提示会另起一行追加，保留原有文本、行内引用和附件。该菜单还提供“手动创建”。手动创建与已有任务打开同一编辑页，校验必填项并保存任务，不启动 Agent 或发送指令。请求失败时保留表单和已填内容。空态显示装饰性的文档与时钟插图，其颜色随主题变化。

“已开启”“已暂停”“已结束”“全部”筛选结合标题、指令和关联会话 id 搜索，默认显示已开启任务。搜索行菜单在确认后清除全部已结束任务，保留已开启和已暂停任务。选择任务直接打开可编辑的“规则 / 任务运行记录”页面。只有字段有效且有实际修改时才能保存；保存只发送变更字段及 `expectedUpdatedAt`，存储版本缺失时发送 `null`。保存后字段保持可编辑。切换任务或离开页面时保留未保存的草稿。冲突保留整份草稿并禁用保存。“保留修改并复核”将改过的字段组应用到最新值，供保存前复核；“放弃”用最新存储值替换草稿。对于新任务，“放弃”关闭编辑页。迟到响应不会改变其他任务详情。粗指针设备的搜索、指令和时间字段使用 16px 字号，避免 iOS Safari 聚焦时缩放。

执行位置下拉提供“新建对话并复用”和“每次新建对话”，手动创建默认前者。已经关联会话的任务，执行位置显示“当前关联对话”；编辑时保留原目标，只有用户主动选择新方式才会切换。“关联工作区”选择器列出框架工作区目录，在每个工作区名称下显示其路径，并以本地化默认名称标注首次使用时创建的工作区。新的执行位置默认使用该工作区；没有该工作区时使用列表中的第一个。没有目录的已有任务显示“未分组”，因为它创建的会话不加入任何工作区。复用目标的首次会话尚未存在时，详情底部入口显示“待创建”。每次新建的目标在首次投递后显示“最近运行对话”，首次投递前隐藏该入口；更早的对话仍可从任务运行记录进入。可用链接在打开前再次检查会话是否仍存在、是否归档；缺失或归档会话保持禁用。

重复编辑提供仅一次、每分钟、每小时、每天、每周、每月和自定义规则。日期和时间控件复用已有选择器。引导选项生成 RRULE；分钟和小时间隔从所选时区的当前分钟开始。自定义选项和自定义输入框不提示任何语法名称；输入框接受两行 RRULE 或带显式时区的五字段 Cron。RRULE 在 `DTSTART` 中保留时区；Cron 将表达式和所选时区保留为 Cron 时间类型。复杂 RRULE 保持原文。新的或已修改的自定义文本由共享时间解析器校验，校验通过后才能保存；无效或空输入保留草稿，并说明需要修改的字段。自定义文本无效时，提示手动修改规则、选择其他重复方式，或让智能体修改规则。宿主在保存时执行最终校验。已有 After、At 任务直接显示日期和时间控件；本地时间重复时，必要时使用 UTC 保留准确时点。Every、Daily、Weekly 任务在控件可表示其间隔或钟表时间精度时直接显示对应控件；其他时间规则仍在自定义中显示描述，并在替换前保留原类型。查看任务或编辑其他字段保留其时间规则及已提交发生时点。

暂停和恢复修改生命周期状态。有未保存修改时，先保存或放弃更改，才能暂停、恢复、立即执行或删除。详情菜单提供立即执行和删除，不提供取消排队消息：同一条收件箱消息可能包含多个任务的投递。投递到复用对话的投递排队或执行期间，详情禁用字段、保存、暂停与恢复、立即执行和删除，并说明此任务已排队或执行中，请在会话中管理任务；详情底部的会话入口打开该会话。最小投递间隔结束前禁用再次立即执行，执行空闲后仍可暂停或删除。仅因间隔禁用时，立即执行项仍可聚焦，其提示说明未满最小运行间隔，并给出可以立即执行的时间。已经关联会话的任务，其关联对话已归档时，同样禁用立即执行，因为宿主拒绝这次投递。宿主以 `schedule_execution_pending` 拒绝的立即执行显示为状态提示，而非错误。删除需要确认，移除任务及其已保存记录，保留会话和已经投递的消息，并通过现有应用级提示报告结果。确认对话框首先聚焦“取消”；对话框关闭后，焦点回到详情菜单按钮。宿主答复之前，详情保持显示该任务。删除生效后关闭详情或其任务页签；删除失败时保留任务，以便再次尝试。

列表、详情、页头和会话悬浮内容的下次运行时间，取计划发生时间和宿主最早允许投递时间中较晚的一项。创建和编辑“每次新建对话”时，通过 `schedule.deliveryLimits` 读取宿主配置，以一句短提示显示最小间隔；读取失败可重试。定时与立即执行共用此限制。

“任务运行记录”按需请求 20 条已保存投递，支持从新到旧分页，失败时保留已加载记录，并忽略被刷新替代或卸载后的请求。每条记录显示投递发生时间与已保存指令，长指令可展开、收起；缺少指令的旧记录不使用当前指令替代。回执的实际执行会话可用时提供入口。仅在最后一页且确认裁剪后显示清理提示，并提供当前保留规则说明。这些记录确认收件箱投递，不表示模型执行成功。

打开会话的页头时钟在首次读取成功之前或没有活动关联任务时保持隐藏。一个任务直接打开右侧栏页签；多个任务打开现有弹层。空闲、未归档且有活动关联任务的会话行保留时钟标记和悬浮列表。`schedule_create` 继续在轮次末尾渲染任务卡片，显示标题、重复描述和“打开”操作。持久化的旧工具结果与当前结果均可渲染；比卡片更新的权威读取同步后续修改或删除。

### 时区数据来源

时区清单和本地化名称通过 `Intl` 使用浏览器内嵌的 ICU/CLDR 数据，不在运行时下载。选择器保留清单未列出的已存储别名；无法枚举时使用系统时区和 UTC。

## 理解实现

任务菜单使用[标准菜单几何](../../../docs/ui-radius.zh.md#nested-hover)，包含键盘高亮行。使用 portal 的任务菜单和日期、时间选择器通过 `useAnchoredPosition`，在浏览器缩放、滚动和尺寸变化时跟随触发器，并保留视口边距和桌面标题栏避让。视觉视口过窄时，任务菜单文案和时间值以省略号截断。时间列随面板缩窄，并在可用高度内纵向滚动；任务菜单通过纵向滚动到达每个选项。会话页头弹层遵循同样的视口限制，并在首次定位完成前保持隐藏。

<summary>实现内部细节 — 点击展开</summary>

Peer 可读取 `schedule/catalog` 时，插件注册现有 `schedules` 主面板、会话页头功能位、轮次尾部卡片、会话行标记与悬浮内容，以及 `scheduleTask` 右侧栏页签。槽位注入提供框架读取器与操作回调；组件拥有选择、搜索和分页状态。入口声明的存储在根或会话作用域中按任务保留草稿和 CAS 基线，支持导航后恢复；主面板与会话页签的草稿相互独立。未修改的表单跟随目录更新。已修改的表单保留全部字段及原版本。目录出现新版本后，须放弃草稿，或由用户明确将改过的名称、内容、时间和目标字段组重新应用到该版本，才能保存。此操作不写入任务；用户复核结果后，以新版本作为 CAS 基线保存。未修改的字段组采用新记录的值。任务缺失时保留可编辑的本地草稿，宿主修改操作仍禁用。草稿不持久化；客户端重新加载，或所属入口、会话作用域销毁时，草稿随之释放。宿主拥有任务存储与执行。浏览目录不会激活会话。冲突反馈沿用目录提示样式；复核按钮采用描边样式，在窄面板中换到提示下方。

修改类型化日历时间时，通过共享重复规则求值器查找首个有效未来发生时点，并保留跨夏令时缺口的间隔对齐。成功编辑沿用 Schedule 的[当前格式写入路径](../../schedule/schedule/README.zh.md)；仅修改内容时保留时间类型、精度、表达式及已提交发生时点。

管理页、任务页签、行标记和会话页头投影共享一个可观察的 `schedule.catalog` 数据源。页头与会话行根据关联关系和执行目标筛选活动记录。修改使用基于任务 id 的 `schedule.create`、`schedule.edit` 和 `schedule.run`；历史使用任务标识和游标，不携带会话所有权参数。修改确认后发起新的权威读取；回读失败仍是目录错误，不将已经确认的写入改判为失败。

侧栏布局记录不保存打开参数，因此 `TaskTabBindings` 按会话和页签 id 在 localStorage 中保存任务标识，不保存任务内容，并清理已关闭页签的关联。可观察目录仅在被读取时订阅，在 Schedule 变更或连接重置时刷新，最后一个订阅退出后使未完成读取失效。

## 模型体验

无：本浏览器包不注册模型工具或自动消息；创建提示保留为未发送的草稿。

#### KV Cache 影响

无。任务列表内容不进入模型请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 已保存记录描述收件箱投递，不表示执行结果；无法重建缺失的历史指令或已物理删除的任务。
- 宿主通过 `deliveryHistoryDays` 和 `deliveryHistoryRecords` 限制历史；分页大小限制记录数量，不限制指令字节数。
- 会话入口通过普通导航打开会话，不跳转到特定消息。删除任务不会取消已投递的消息。
- 此 UI 不为模型工具提供任务级授权。宿主 Schedule 拥有访问控制，任何按会话限制都必须由宿主执行。
