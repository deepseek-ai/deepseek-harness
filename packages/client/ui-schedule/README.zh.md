# @deepseek-ai/dsh-client-ui-schedule

[English](README.md) | 中文

## 概述

自动化任务页和右侧栏任务页签共用任务规则、本地编辑、已保存的投递记录、删除及会话导航。手动创建和执行目标选择使用宿主的 Schedule 服务；会话卡片、页头时钟和会话行标记保留现有位置。

## 使用本包

宽度小于 768px 时，任务列表使用 20px 的左右内边距，与插件页一致。

发布的 Web 组合将 `ui-schedule` 与宿主 Schedule 一起挂载。自动化任务侧栏入口打开任务列表，不选择或激活会话。“新建”保留现有行为：进入新会话，由用户输入指令。相邻下拉提供“在对话中创建”和“手动创建”。手动创建打开共用 Modal，校验必填项并保存任务，不启动 Agent 或发送指令。请求失败时保留表单和已填内容。空态显示装饰性的文档与时钟插图，其颜色随主题变化。

“已开启”“已暂停”“已结束”“全部”筛选结合标题、指令和关联会话 id 搜索，默认显示已开启任务。搜索行菜单在确认后清除全部已结束任务，保留已开启和已暂停任务。选择任务打开“规则 / 任务运行记录”。编辑暂存草稿；保存发送变更字段及 `expectedUpdatedAt`，存储版本缺失时发送 `null`。未改动的保存仍要求宿主写入当前行格式。成功后返回只读视图并聚焦“编辑”。冲突保留草稿并提供“重新加载”；取消丢弃草稿。迟到响应不会改变其他任务详情。粗指针设备的搜索、指令和时间字段使用 16px 字号，避免 iOS Safari 聚焦时缩放。

执行位置下拉提供“新建对话并复用”和“每次新建对话”，手动创建默认前者。已经关联会话的任务，执行位置显示“当前关联对话”；编辑时保留原目标，只有用户主动选择新方式才会切换。“关联工作区”选择器列出框架工作区目录，在每个工作区名称下显示其路径，并以本地化默认名称标注首次使用时创建的工作区。新的执行位置默认使用该工作区；没有该工作区时使用列表中的第一个。没有目录的已有任务显示“未分组”，因为它创建的会话不加入任何工作区。复用目标的首次会话尚未存在时，详情底部入口显示“待创建”。每次新建的目标在首次投递后显示“最近运行对话”，首次投递前隐藏该入口；更早的对话仍可从任务运行记录进入。可用链接在打开前再次检查会话是否仍存在、是否归档；缺失或归档会话保持禁用。

重复编辑提供仅一次、每分钟、每小时、每天、每周、每月和自定义规则。日期和时间控件复用已有选择器。引导选项生成 RRULE；分钟和小时间隔从所选时区的当前分钟开始。自定义选项和自定义输入框不提示任何语法名称；输入框接受两行 RRULE 或带显式时区的五字段 Cron。RRULE 在 `DTSTART` 中保留时区；Cron 将表达式和所选时区保留为 Cron 时间类型。复杂 RRULE 保持原文。保存通过 Host 校验自定义文本；无效或空输入保持草稿打开，并显示已有纠正提示。已有 After、At、Every、Daily、Weekly 记录在自定义中显示描述，并在输入替代规则前保留原类型。编辑其他字段保留已提交发生时点。

暂停和恢复修改生命周期状态。详情菜单提供立即执行和删除，不提供取消排队消息：同一条收件箱消息可能包含多个任务的投递。投递到复用对话的投递排队或执行期间，详情禁用编辑、暂停与恢复、立即执行和删除，并说明此任务已排队或执行中，请在会话中管理任务；详情底部的会话入口打开该会话。最小投递间隔结束前禁用再次立即执行，执行空闲后仍可暂停或删除。仅因间隔禁用时，立即执行项仍可聚焦，其提示说明未满最小运行间隔，并给出可以立即执行的时间。已经关联会话的任务，其关联对话已归档时，同样禁用立即执行，因为宿主拒绝这次投递。宿主以 `schedule_execution_pending` 拒绝的立即执行显示为状态提示，而非错误。删除需要确认，移除任务及其已保存记录，保留会话和已经投递的消息，并通过现有应用级提示报告结果。确认对话框首先聚焦“取消”；对话框关闭后，焦点回到详情菜单按钮。宿主答复之前，详情保持显示该任务。删除生效后关闭详情或其任务页签；删除失败时保留任务，以便再次尝试。

列表、详情、页头和会话悬浮内容的下次运行时间，取计划发生时间和宿主最早允许投递时间中较晚的一项。创建和编辑“每次新建对话”时，通过 `schedule.deliveryLimits` 读取宿主配置，以一句短提示显示最小间隔；读取失败可重试。只读详情保留下次运行时间，不重复该提示。定时与立即执行共用此限制。

“任务运行记录”按需请求 20 条已保存投递，支持从新到旧分页，失败时保留已加载记录，并忽略被刷新替代或卸载后的请求。每条记录显示投递发生时间与已保存指令，长指令可展开、收起；缺少指令的旧记录不使用当前指令替代。回执的实际执行会话可用时提供入口。仅在最后一页且确认裁剪后显示清理提示，并提供当前保留规则说明。这些记录确认收件箱投递，不表示模型执行成功。

打开会话的页头时钟在首次读取成功之前或没有活动关联任务时保持隐藏。一个任务直接打开右侧栏页签；多个任务打开现有弹层。空闲、未归档且有活动关联任务的会话行保留时钟标记和悬浮列表。`schedule_create` 继续在轮次末尾渲染任务卡片，显示标题、重复描述和“打开”操作。持久化的旧工具结果与当前结果均可渲染；比卡片更新的权威读取同步后续修改或删除。

### 时区数据来源

时区清单和本地化名称通过 `Intl` 使用浏览器内嵌的 ICU/CLDR 数据，不在运行时下载。选择器保留清单未列出的已存储别名；无法枚举时使用系统时区和 UTC。

## 理解实现

<details>
<summary>实现内部细节 — 点击展开</summary>

Peer 可读取 `schedule/catalog` 时，插件注册现有 `schedules` 主面板、会话页头功能位、轮次尾部卡片、会话行标记与悬浮内容，以及 `scheduleTask` 右侧栏页签。槽位注入提供框架读取器与操作回调；组件拥有可丢弃的选择、搜索、表单和分页状态。宿主拥有任务存储与执行。浏览目录不会激活会话。

管理页、任务页签、行标记和会话页头投影共享一个可观察的 `schedule.catalog` 数据源。页头与会话行根据关联关系和执行目标筛选活动记录。修改使用基于任务 id 的 `schedule.create`、`schedule.edit` 和 `schedule.run`；历史使用任务标识和游标，不携带会话所有权参数。修改确认后发起新的权威读取；回读失败仍是目录错误，不将已经确认的写入改判为失败。

侧栏布局记录不保存打开参数，因此 `TaskTabBindings` 按会话和页签 id 在 localStorage 中保存任务标识，不保存任务内容，并清理已关闭页签的关联。可观察目录仅在被读取时订阅，在 Schedule 变更或连接重置时刷新，最后一个订阅退出后使未完成读取失效。

</details>

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 已保存记录描述收件箱投递，不表示执行结果；无法重建缺失的历史指令或已物理删除的任务。
- 宿主通过 `deliveryHistoryDays` 和 `deliveryHistoryRecords` 限制历史；分页大小限制记录数量，不限制指令字节数。
- 会话入口通过普通导航打开会话，不跳转到特定消息。删除任务不会取消已投递的消息。
- 此 UI 不为模型工具提供任务级授权。宿主 Schedule 拥有访问控制，任何按会话限制都必须由宿主执行。
