# @deepseek-ai/dsh-client-ui-plugin-recommendations

[English](README.md) | 中文

## 概述

用户在完整回答下方看到一张插件推荐卡片，显示插件当前的界面语言标题和描述。标题和描述是同一个点击区域，悬停时整体高亮；点击可打开插件页中的对应详情，不会启用插件或改变当前 Session。启用和暂不需要仍是独立操作。profile 里还没有的连接器，卡片以普通文字显示它自己的标题和描述，提供「安装并启用」，并列出 pnpm 拦下、等待允许的安装脚本。已启用的连接器，卡片在状态旁边提供「连接账号」；已选择「暂不需要」或最近一次尝试失败的卡片不提供。重新连接后仍能看到之前的选择并打开详情。

## 使用本包

Web 组合（[`dsh-web-app`](../../bundle/web-app/README.zh.md)）会挂载本包。这个浏览器端贡献没有配置项；它为 `enable_official_plugin` 卡片填充共享的[操作卡片框架](../ui-action-cards/README.zh.md)。

<a id="understand-the-implementation"></a>
## 实现原理

<details>
<summary>实现细节 — 点击展开</summary>

插件先挂载读取目录文本的 Remote，再向共享的卡片框架注册正文；框架把卡片放在所在回合之后，并提供卡片、已记录的决定和绑定到卡片的操作。正文向 Host 读取插件当前的目录文本和启用状态（每次操作之后再读一次），渲染带「官方」标记的标题栏、详情点击区域、状态，以及通过框架操作发出的启用和暂不需要。详情点击区域的无障碍名称是「查看详情」加插件标题，目录描述仍作为它的无障碍描述。查询被拒绝时显示原因，回复丢失时说明无法读取插件信息；两种情况都提供「暂不需要」和重新查询的「重试」，不提供启用。卡片没有写插件名时显示框架的后备内容，只提供「暂不需要」。profile 未持有的连接器在安装之前没有详情页，卡片按同样的布局以普通文字显示 Host 从连接器目录读到的标题和描述，不提供详情点击区域。它的主按钮是「安装并启用」；安装失败并记录了被拦下的安装脚本后，卡片列出这些脚本，主按钮变为「允许这些脚本并重试」。这段授权说明和这个按钮在每种语言里都沿用插件页允许安装脚本时的文字，同一项授权在哪里询问，措辞都一样。安装失败时，状态文字说明安装自己的恢复办法，不再显示插件管理的错误提示，版本不兼容的提示除外。已启用的连接器，卡片把状态和「连接账号」按钮放在同一行底栏里；已选择「暂不需要」或最近一次尝试失败的卡片不显示这个按钮。「连接账号」和详情点击区域一样，通过插件页导航打开详情页。已记录的结果保持不变，插件之后离开目录也一样。操作进行中只有被点击的按钮显示「正在处理…」（安装时显示「正在安装…」），两个按钮都禁用。插件在自身生命周期内按插件名记住读到的目录文本，再次进入会话时卡片立即显示，同时卡片自己的查询会刷新启用状态；查询发现连接器已不在 profile 里时，这张卡片不再使用记住的文本。某个插件的第一次查询返回前，卡片显示提议的标题、一行描述占位和禁用的按钮，布局不跳动。Remote、正文注册和词典共用同一个插件生命周期。

卡片沿用应用字体，通过标题、正文和独立操作区区分信息层级。读取目录文本的 Remote 由 [`api-remotes`](../../api/remotes/README.zh.md) 挂载。插件页只在当前 Peer 可以使用时提供 `pluginNavigation`；插件只在这段时间注册正文，否则[共享框架](../ui-action-cards/README.zh.md)只提供「暂不需要」。

<a id="model-experience"></a>
## 模型体验

间接影响来自卡片操作：共享的 Host 卡片服务在下一次模型请求中追加一条已记录的状态通知。本界面不增加模型工具或提示词。

#### KV Cache effect

卡片不增加模型上下文。「启用」「安装并启用」和「允许这些脚本并重试」都可能通过 Host 改变之后的工具声明。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 每个回合只显示第一条推荐。
- 插件第一次查询返回前，卡片只预留一行描述；更长的描述返回后卡片仍会变高。
- 历史选择不会跟踪之后在插件页面进行的修改。
- 查询被拒绝或回复丢失后，要等之后的一次查询（「重试」或某次操作之后的查询）读到插件的目录文本，才会重新提供启用。
- 插件离开目录后，卡片显示提议时的标题，而不是目录文本。
- 连接器安装之前，卡片在第一次查询返回前先显示提议的标题和一行占位。
- 「连接账号」只负责打开连接器的详情页，卡片不显示账号是否已连接。
