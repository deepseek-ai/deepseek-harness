要求在新分支上工作时，智能体会转到一个单独的文件夹中进行这项工作。你当前的工作树及其未提交的更改保持原样。

## 使用方法

- 让智能体在新分支上工作，可以指定分支名，以及作为起点的本地分支、标签或提交。默认从你当前的提交开始，并生成以 `worktree-` 开头的名称。
- 对话中会出现 `create_worktree` 的 **工具调用** 行；展开即可看到新路径和分支。
- 如需返回，请让智能体切换到你的主工作树。新工作树和分支会保留。

## 注意事项

- 新工作树创建在当前工作树中的 `.agents/worktrees/<name>`。如果该文件夹由 DSH 新建，DSH 会在其中添加 `.gitignore`，让 Git 忽略它。
- 只会检出已提交的文件：未提交和被忽略的文件（如 `node_modules`）不会被复制，子模块不会被初始化，依赖也不会被安装。DSH 不会从远程仓库拉取，Git LFS 文件保持为指针文件。
- 如果分支或文件夹已存在，或者访问模式不允许写入该文件夹和仓库的 Git 数据，调用会失败。失败的调用可能留下不完整的工作树，错误信息会给出其路径。
- 关闭此插件不会删除它创建的工作树和分支；请用 Git 自行删除。
