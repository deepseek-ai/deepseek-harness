把从 chat.deepseek.com 导出的会话导入到一个工作区，然后继续对话。

在插件页的「更多」（实验性插件）里打开这个插件，再点「新会话」旁的上传箭头，选择 `deepseek_data-*.zip` 文件和接收会话的工作区，按「导入」。对话框会先显示上传，再显示导入了多少个会话。

每个导出会话生成一个会话：你当时停留的那条分支、原标题与时间、思考、联网搜索与网页卡片、以及图片。被撤回、失败或由模板回答的回复显示为错误行，不进入模型上下文；如果一个会话的提问全部被撤回，就跳过该会话。

导入只接受 ZIP 文件，且只对 owner 开放：共享访客看不到这个按钮。一次导入最多写入 `maxSessions` 个会话（默认 1000），单个压缩包最大 `maxUploadBytes`（512 MiB），单个条目解压后最大 `maxEntryBytes`（256 MiB），标题按 `maxTitleBytes`（80）截断。同一个文件导入两次会得到两份会话副本。

失败原因、事件映射和已知限制见包的 README。
