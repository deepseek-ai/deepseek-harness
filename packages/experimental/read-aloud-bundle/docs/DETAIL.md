Select the speaker under a finished reply to hear it, and select it again to stop. Choose the voice below; the speaker beside it plays a short sample.

A reply is sent to speech synthesis one segment at a time as playback advances, so a reading stopped early is billed only for the segments already requested. Code blocks, tables, and formulas are not read.

Reading supports Mandarin, Cantonese, English, Japanese, Korean, Malay, Arabic, Indonesian, Thai, and Vietnamese. The language is detected from the reply's text.
